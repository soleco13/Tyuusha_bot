# Бот печати: игральные карты из фото + печать фото

Бот работает на компьютере, к которому подключён принтер (сейчас — Epson L3250).
Вместе с ботом запускается веб-панель заказов. Оплаты пока нет: заказ сразу попадает
оператору и печатается, только когда оператор нажмёт «🖨 Печать» в панели или в Telegram.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Запустите `install.bat` — создастся окружение и файл `.env`.
3. В `.env` впишите `BOT_TOKEN`. Запустите `run.bat`, напишите боту `/myid`,
   впишите полученный ID в `ADMIN_IDS` и перезапустите `run.bat`.
4. Отправьте боту `/testprint` — выйдет пробный лист. Линейкой проверьте,
   что квадрат ровно 50×50 мм (значит, карты будут ровно 63×88 мм).

Бот и панель работают, пока открыто окно `run.bat` и компьютер не спит.

## Панель заказов

Откройте в браузере **http://127.0.0.1:8080** (адрес — в `ADMIN_URL`, команда `/admin` в боте),
пароль — `ADMIN_PASSWORD` в `.env`.

- **Вкладки**: В работе / Ждут выдачи / Выданы / Отменены / Все, поиск по №, имени, @нику.
- **Карточка заказа**: клиент и ссылка на его Telegram, состав и стоимость, листы для печати
  и фото клиента (с просмотром), заметка оператора, история всех событий.
- **Действия**: Печать (с напоминанием подготовить бумагу), Печать рубашек, Напечатать заново,
  Снять с принтера, Выдан клиенту, Отменить (с причиной — клиент её увидит),
  Написать клиенту, скачать листы ZIP.
- **Принтер** (кнопка в шапке): ошибки (нет бумаги, не в сети…) и очередь заданий Windows.
  Печать отслеживается по очереди: «в очереди → печатается → напечатано» или ошибка.
- **Цены**: колоды, изделия, фото по форматам, надбавки за бумагу и качество, улучшение фото.
- **Склад**: бумага, картон, фотобумага, самоклейка, плёнка для ламинации и запас чернил.
  Материалы списываются при оформлении заказа, возвращаются при отмене до печати, при перепечатке
  списываются ещё раз. Приход, списание, точный остаток и порог «мало» — на карточке материала,
  движения — в журнале. Когда запас доходит до порога, операторам приходит сообщение; когда
  материал закончился, клиенты не смогут выбрать бумагу на нём, а заказ не оформится.
- **Статистика**: выручка, заказы и средний чек за 7/30/90 дней и год, выручка по дням,
  что заказывают, популярные рубашки, расход материалов, повторные клиенты.
- **Этап заказа для клиента** (в карточке заказа): «Режем и собираем», «Упаковываем»,
  «Готово к выдаче» или просто «Фото заказа» — с фото готового заказа и парой слов.
  Клиент получает фото в Telegram и видит этап в приложении.
- Панель обновляется сама каждые 4 секунды, новый заказ — уведомление (и звук, если включён).

Статусы заказа: 🆕 новый → 🖨 печатается → (карты: 🔄 ждёт рубашек) → 📦 напечатан → ✅ выдан;
или ✖️ отменён. Клиент получает сообщение на каждом шаге и видит всё в «📦 Мои заказы».

Открыть панель с телефона в той же сети: `ADMIN_HOST=0.0.0.0`, затем адрес
`http://<IP-компьютера>:8080`.

## Что умеет

**Пользователь**
- 🃏 Игральные карты: шаблон «36 карт» или «54 карты (с джокерами)» → загрузка
  1–54 фото → превью с водяным знаком → «Оформить заказ».
- 🖼 Печать фото: загрузка фото → формат (10×15 / A5 / A4) → копии → цвет/ЧБ →
  качество → превью → «Оформить заказ».

**Подарки из фото** (Mini App, раздел «Подарки» — `products.py`): мемори (6–24 пары карточек 63×63),
карты для свиданий (4 набора вопросов + свои), карты желаний (свои желания + пустые карточки),
наклейки (фон вырезается нейросетью, белая обводка), фотокалендарь (обложка + 12 месяцев, праздники
выделены), открытки (фото с надписью, на обороте — текст и строки адреса), коробка для колоды
(развёртка на картоне) и карты для своей настольной игры из таблицы CSV (образец —
`miniapp/sample_game.csv`). Экран конструктора строится по описанию полей с сервера, образец
изделия и цена приходят с `/mapi/preview`.

**Для всех заказов**: выбор бумаги (картон или картон с ламинацией, фотобумага или плотная матовая,
обычная или плотная) с надбавкой за лист; улучшение слабых фото нейросетью (по желанию, за доплату);
кадр по лицу — лица на картах, в овалах UNO, в календаре и открытках не срезаются; перед заказом
карточку можно покрутить в 3D и увидеть и лицо, и рубашку.

**Оператор** (ID из `ADMIN_IDS`)
- Получает уведомление о новом заказе со ссылкой на панель и кнопкой «🖨 Печать».
- Карты печатаются в два прохода: сначала лицевые листы, потом бот просит
  перевернуть стопку и нажать «Печать рубашек» (у L3250 нет автодуплекса).
- `/admin` — ссылка на панель, `/printers` — состояние принтера, `/testprint` — пробный лист.

## Настройки `.env`

| Параметр | Что это |
|---|---|
| `BOT_TOKEN` | токен от BotFather |
| `ADMIN_IDS` | ID операторов через запятую |
| `PRINTER_NAME` | имя принтера Windows (`EPSON L3250 Series` — USB, `L3250 Series(Сеть)` — по Wi-Fi); пусто — принтер по умолчанию |
| `PRINT_MODE` | `agent` — печать через программу «Тюша Печать» на компьютере с принтером (для сервера); `printer` — принтер подключён к этому же компьютеру; `browser` — окно печати браузера; `file` — только сохранять листы в `data/printed` |
| `ADMIN_PASSWORD` | пароль панели заказов |
| `ADMIN_HOST`, `ADMIN_PORT` | адрес панели (по умолчанию `127.0.0.1:8080`) |

## Советы по картам

- Бумага: матовая/глянцевая фотобумага 200–300 г/м². Для толстой бумаги подавайте
  по 1–5 листов.
- Перед первым заказом напечатайте 1 лицевой лист и 1 рубашку на обычной бумаге
  и посмотрите на просвет, как совпадают. Рубашка симметричная, поэтому небольшой
  сдвиг почти не заметен.
- Резать по меткам на полях: карты стоят вплотную, один рез разделяет две карты.
  Удобно резаком для бумаги, углы — уголкорезом R3.

## Оформление (Тюша)

- `assets/tyusha_*.webp` — референсы персонажа.
- `assets/anim/*.gif` — анимации: `hello` (машет лапкой), `thinking` (собирает макет),
  `printing` (печатает на принтере), `done` (радуется с конфетти), `oops` (ошибка/отказ).
  Пересобрать после изменений: `.venv\Scripts\python make_animations.py`.
- Лицевая сторона карты: крупный засечный ранг и масть в углах (как в классической колоде), фото по центру
  с мягко растворяющимися краями. Масти рисуются векторно, ранги — шрифтом PT Serif из `assets/fonts`
  (лицензия OFL), поэтому карты одинаковые на Windows и на Linux-сервере.
- Рубашки на выбор клиента — на всю карту, без рамок: «Сердечки», «Шотландка», «Звёздная ночь»,
  «Мятный горошек», «Ромашки». Код — `cards.py` (`BACKS`), картинки для Mini App — `miniapp/img/backs/`
  (пересоздать: `cards.save_back_previews(Path("miniapp/img/backs"))`). На листах рубашек узор выходит
  за линию реза на 1,2 мм, чтобы при неточном резе не было белой каймы.
- Команды меню и описание бота бот выставляет сам при запуске.
- Вручную в @BotFather → ваш бот → Edit Bot:
  - **Edit Botpic** — загрузите `assets/anim/avatar.png`;
  - **Edit Description Picture** — загрузите `assets/anim/description.gif` (640×360).

## Печать через компьютер с принтером (PRINT_MODE=agent) — основной способ

Бот и панель стоят на сервере, принтер — у вас. На компьютере с принтером работает программа
**«Тюша Печать»**: она сама подключается к серверу, получает задания со всеми настройками,
печатает и сообщает статус. Оператору ничего настраивать не нужно — он нажимает «Печать» в заказе
и следит за бумагой и статусом.

```
Оператор (любой браузер) → «Печать» → сервер → задание + настройки → «Тюша Печать» → принтер
                                                 ← получено / печатается / нет бумаги / напечатано ←
```

**Один раз на сервере:** в `.env` укажите `PRINT_MODE=agent` и перезапустите бота. Кнопка «Скачать программу»
в панели отдаёт последнюю версию с GitHub Releases — класть exe на сервер не нужно.

**Один раз на каждом компьютере с принтером:**
1. Панель → «Принтеры» → «Подключить компьютер» — появится код на 10 минут.
2. На компьютере скачайте программу (кнопка в панели или [последний релиз](https://github.com/soleco13/Tyuusha_bot/releases/latest)), запустите `TyushaPrint.exe`, введите адрес сервера и код. Если у сервера самоподписанный
   сертификат, программа покажет его отпечаток и попросит подтвердить — дальше запомнит его.
3. Готово: компьютер появится в «Принтерах», профили привяжутся к его принтеру по умолчанию.
4. По желанию: в программе у профиля нажмите «Настроить…» — откроется окно драйвера Epson.
   Выберите тип бумаги, качество — эти настройки будут применяться к каждому заказу этого профиля.
5. В панели у профиля нажмите «Пробный лист» — квадрат на листе должен быть ровно 50 мм.

**Профили печати** — это материалы: «Игральные карты (картон 300 г/м²)» и «Фото». Для каждого выбирается
компьютер, принтер и настройки драйвера. Заказ сам выбирает свой профиль; размер листа A4 и масштаб 1:1
не меняются никогда, цвет/ч-б берётся из заказа.

**Что видно оператору:** в шапке панели — состояние принтера («готов», «нет бумаги», «компьютер не на связи»),
в окне «Печать» — куда уйдёт задание, в карточке заказа — ход печати по шагам. Если компьютер выключен,
печать не начнётся — панель сразу скажет почему. Если связь пропала во время печати, заказ вернётся в
прежний статус с пометкой «проверьте, что напечаталось».

**Работает без присмотра:**
- Профили печати и параметры работы программа получает с сервера при каждом опросе — на компьютерах ничего
  не переписывается.
- **Обновляется сама.** Раз в 6 часов проверяет GitHub Releases, скачивает новую версию, сверяет контрольную сумму,
  запускает самопроверку нового exe и ставит его, когда принтер свободен. Сразу — кнопкой «Обновить сейчас»
  в панели («Принтеры») или «Проверить обновления» в программе.
- **Поднимается сама.** Надсмотрщик перезапускает программу после сбоя; сторож перезапускает её, если опрос
  сервера завис; журналы не разрастаются (`%APPDATA%/TyushaPrint/agent.log`, `supervisor.log`).
- Сама держит связь с сервером (белый IP не нужен), повторяет запросы при сбоях сети, каждое задание печатается
  один раз, задание без движения 20 минут — сигнал оператору, компьютер не засыпает, автозапуск с Windows.
- Операторам приходит сообщение в Telegram, если компьютер с принтером пропал со связи и когда вернулся.
- Отключить компьютер — в панели, кнопка «Отключить».

**Как выпустить новую версию программы:** поменяйте `VERSION` в `agent/tyusha_print.py`, закоммитьте и отправьте
тег — `git tag agent-v1.2.0 && git push origin agent-v1.2.0`. GitHub Actions соберёт `TyushaPrint.exe`, проверит
его и опубликует релиз; все установленные программы обновятся сами.

**Собрать вручную:** `agent/build_agent.bat` на Windows (нужен `install.bat`) → `agent/dist/TyushaPrint.exe`.
Запуск из исходников без сборки — `agent/run_agent.bat` (такая копия обновляется через `git pull`).
Проверка без бумаги: переменная окружения `TYUSHA_DRY_RUN=1` — листы сохраняются в `%APPDATA%/TyushaPrint/dry_run`.

## Печать из браузера (PRINT_MODE=browser) — запасной способ

Бот и админка стоят на сервере; принтер подключён к компьютеру оператора. Оператор открывает админку
в браузере на этом компьютере. Кнопка «Печать» открывает страницу с листами A4 в реальный размер
и сразу вызывает окно печати браузера. В окне печати: принтер Epson, бумага A4, масштаб 100 %, поля — «нет».
После печати оператор нажимает «Напечатано» (или «Не получилось») — клиент получает уведомление.
Пробный лист: `/testprint` в боте (откроет `…/print/test`). Режимы `printer` (Windows-принтер без браузера) и `file` остались для особых случаев.
