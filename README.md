# Бот печати: игральные карты из фото + печать фото

Бот работает на компьютере, к которому подключён принтер (сейчас — Epson L3250).
Вместе с ботом запускается веб-панель заказов. Оплаты пока нет: заказ сразу попадает
оператору и печатается, только когда оператор нажмёт «🖨 Печать» в панели или в Telegram.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Запустите `install.bat` — создастся окружение и файл `.env`.
3. В `.env` впишите `BOT_TOKEN`. Запустите `run.bat`, напишите боту `/myid`,
   впишите полученный ID в `ADMIN_IDS` и перезапустите `run.bat`.
4. Отправьте боту `/testprint` — выйдет пробный лист. Линейкой проверьте,
   что квадрат ровно 50×50 мм (значит, карты будут ровно 63×88 мм).

Бот и панель работают, пока открыто окно `run.bat` и компьютер не спит.

## Панель заказов

Откройте в браузере **http://127.0.0.1:8080** (адрес — в `ADMIN_URL`, команда `/admin` в боте),
пароль — `ADMIN_PASSWORD` в `.env`.

- **Вкладки**: В работе / Ждут выдачи / Выданы / Отменены / Все, поиск по №, имени, @нику.
- **Карточка заказа**: клиент и ссылка на его Telegram, состав и стоимость, листы для печати
  и фото клиента (с просмотром), заметка оператора, история всех событий.
- **Действия**: Печать (с напоминанием подготовить бумагу), Печать рубашек, Напечатать заново,
  Снять с принтера, Выдан клиенту, Отменить (с причиной — клиент её увидит),
  Написать клиенту, скачать листы ZIP.
- **Принтер** (кнопка в шапке): ошибки (нет бумаги, не в сети…) и очередь заданий Windows.
  Печать отслеживается по очереди: «в очереди → печатается → напечатано» или ошибка.
- **Цены**: колоды, фото по форматам, надбавка за качество.
- Панель обновляется сама каждые 4 секунды, новый заказ — уведомление (и звук, если включён).

Статусы заказа: 🆕 новый → 🖨 печатается → (карты: 🔄 ждёт рубашек) → 📦 напечатан → ✅ выдан;
или ✖️ отменён. Клиент получает сообщение на каждом шаге и видит всё в «📦 Мои заказы».

Открыть панель с телефона в той же сети: `ADMIN_HOST=0.0.0.0`, затем адрес
`http://<IP-компьютера>:8080`.

## Что умеет

**Пользователь**
- 🃏 Игральные карты: шаблон «36 карт» или «54 карты (с джокерами)» → загрузка
  1–54 фото → превью с водяным знаком → «Оформить заказ».
- 🖼 Печать фото: загрузка фото → формат (10×15 / A5 / A4) → копии → цвет/ЧБ →
  качество → превью → «Оформить заказ».

**Оператор** (ID из `ADMIN_IDS`)
- Получает уведомление о новом заказе со ссылкой на панель и кнопкой «🖨 Печать».
- Карты печатаются в два прохода: сначала лицевые листы, потом бот просит
  перевернуть стопку и нажать «Печать рубашек» (у L3250 нет автодуплекса).
- `/admin` — ссылка на панель, `/printers` — состояние принтера, `/testprint` — пробный лист.

## Настройки `.env`

| Параметр | Что это |
|---|---|
| `BOT_TOKEN` | токен от BotFather |
| `ADMIN_IDS` | ID операторов через запятую |
| `PRINTER_NAME` | имя принтера Windows (`EPSON L3250 Series` — USB, `L3250 Series(Сеть)` — по Wi-Fi); пусто — принтер по умолчанию |
| `PRINT_MODE` | `printer` — печать; `file` — только сохранять листы в `data/printed` |
| `ADMIN_PASSWORD` | пароль панели заказов |
| `ADMIN_HOST`, `ADMIN_PORT` | адрес панели (по умолчанию `127.0.0.1:8080`) |

## Советы по картам

- Бумага: матовая/глянцевая фотобумага 200–300 г/м². Для толстой бумаги подавайте
  по 1–5 листов.
- Перед первым заказом напечатайте 1 лицевой лист и 1 рубашку на обычной бумаге
  и посмотрите на просвет, как совпадают. Рубашка симметричная, поэтому небольшой
  сдвиг почти не заметен.
- Резать по меткам на полях: карты стоят вплотную, один рез разделяет две карты.
  Удобно резаком для бумаги, углы — уголкорезом R3.

## Оформление (Тюша)

- `assets/tyusha_*.webp` — референсы персонажа.
- `assets/anim/*.gif` — анимации: `hello` (машет лапкой), `thinking` (собирает макет),
  `printing` (печатает на принтере), `done` (радуется с конфетти), `oops` (ошибка/отказ).
  Пересобрать после изменений: `.venv\Scripts\python make_animations.py`.
- Рубашка карт — с медальоном Тюши.
- Команды меню и описание бота бот выставляет сам при запуске.
- Вручную в @BotFather → ваш бот → Edit Bot:
  - **Edit Botpic** — загрузите `assets/anim/avatar.png`;
  - **Edit Description Picture** — загрузите `assets/anim/description.gif` (640×360).

## Файлы

- `bot.py` — сценарий бота, запуск всего
- `service.py` — статусы заказа и действия (печать, выдача, отмена, уведомления)
- `admin_web.py` + `admin/` — веб-панель заказов
- `db.py` — база заказов SQLite (`data/orders.sqlite3`), `pricing.py` — цены
- `cards.py` — шаблон карт, `photos.py` — раскладка фото
- `printing.py` — печать на принтер Windows в масштабе 1:1 и слежение за очередью
- `data/orders/<номер>/` — файлы заказа: исходные фото, листы для печати


## Сервер + компьютер с принтером (режим agent)

Бот, админка и Mini App живут на сервере (`PRINT_MODE=agent`, `AGENT_TOKEN` в `.env`).
Принтер подключён к компьютеру оператора, на нём работает только агент печати:

1. На компьютере: обновить папку бота (`git pull`), **остановить старый `run.bat`** — два бота на одном токене мешают друг другу.
2. В `.env` на компьютере указать `SERVER_URL=https://<адрес сервера>`, `AGENT_TOKEN=<как на сервере>`, `PRINTER_NAME=<имя принтера>`.
3. Запустить `agent\run_agent.bat` (при первом запуске поставит зависимости). Окно держать открытым, компьютер не должен спать.
4. Админка показывает «компьютер с принтером не на связи», пока агент не запущен; «Печать» в этом случае не принимается.

Проверка связи без бумаги: `AGENT_DRY_RUN=1` в `.env` компьютера — листы только сохранятся в `data\agent_printed`.
